## Android Developer Verification Instructions

Android developer verification is designed to link real-world entities (individuals and
organizations) with their Android applications. Android will require all apps to be registered by
verified developers in order to be installed by users on certified Android devices

- https://developer.android.com/developer-verification
- https://github.com/android/security-samples/tree/main/AndroidDeveloperVerificationAPKSigningExample
- https://support.google.com/googleplay/android-developer/answer/16761053?hl=en
