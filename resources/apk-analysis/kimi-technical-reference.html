8.1 WebView vs Native Boundary

# WebView is used ONLY for these features (which require browser engine):
# ├── Mermaid diagrams (SVG rendering, complex layout)
# ├── Markmap mind maps (interactive, zoomable SVG)
# ├── D3.js visualizations (data-driven SVG/Canvas)
# ├── PDF viewing
# └── Yidun (易盾) captcha (security widget)
#
# WebView is NOT used for:
# ├── Code syntax highlighting (Prism4j → SpannableStringBuilder)
# ├── Markdown rendering (Markwon → native Spannables)
# ├── LaTeX math (JLatexMath → native Canvas rendering)
# └── General text/UI (Compose Multiplatform)
