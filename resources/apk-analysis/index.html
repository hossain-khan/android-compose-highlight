Android Syntax Highlighting Analysis

How top AI & developer Android apps implement in-app code syntax highlighting — April–May 2026

This project investigates how major Android apps render syntax-highlighted source code. Each APK was extracted from a device via ADB, decoded with apktool, and analyzed through static inspection of smali bytecode, bundled assets, and resource files.

Highlight.js dominates — four of seven apps use it, but with varying approaches: Claude and Perplexity use a hidden WebView for tokenization then render natively with Compose spans; ChatGPT renders entirely in a WebView; and Le Chat (Mistral) runs hljs directly in the React Native JS thread and renders with RN Text components. GitHub uses server-side highlighting, Replit embeds a full CodeMirror 6 web IDE, and Gemini delegates everything to the Google App (AGSA).

App Investigations

ChatGPT Highlight.js
com.openai.chatgpt
Bundles Highlight.js v11.9.0 with 41 curated languages. Renders code entirely inside a WebView using custom ChatGPT-branded CSS themes. The simplest implementation — no native span conversion.

Claude Highlight.js
com.anthropic.claude
Uses Highlight.js v11.10.0 with all 192 languages. Hidden WebView tokenizes code, then HTML is parsed into native Jetpack Compose AnnotatedString spans via jsoup. Base64 data: URL approach for loading assets.
Analysis Report Technical Reference
GitHub Server-side
com.github.android
No client-side highlighting engine. Code arrives pre-highlighted from GitHub's servers with Primer syntax CSS classes. The app maps pl-* classes to colors and renders via custom StyleSpan subclasses.
Analysis Report Technical Reference
Gemini None
com.google.android.apps.bard
A ~5 MB thin shell that immediately launches the Google App (AGSA) via intent with a Bard deep link, then calls finish(). Contains zero highlighting assets, libraries, or rendering code. All functionality lives in AGSA.
Analysis Report Technical Reference
Perplexity Highlight.js
ai.perplexity.app.android
Highlight.js v11.11.1 (newest) with 192 languages. Uses WebViewAssetLoader for the hidden WebView, parses CSS themes at runtime into a LinkedHashMap, and produces both light and dark Compose spans in a single pass. Ships Berkeley Mono and a proprietary Perplexity Mono font.

Replit CodeMirror 6
com.replit.app
React Native (Expo SDK 54) app that embeds its full web IDE inside a WebView. Uses CodeMirror 6 with Lezer incremental parsing for syntax highlighting. No native highlighting code — the entire workspace is web-rendered. Bundles Hack and JetBrains Mono fonts.

Le Chat Highlight.js
ai.mistral.chat
React Native (Expo SDK 55) app by Mistral AI. Bundles Highlight.js with full language grammars directly in the Hermes bytecode. Tokenization runs in JS and renders natively via React Native Text components styled with NativeWind (Tailwind). Also bundles React Native Skia and Devicon font for language icons.

Key Findings

Highlight.js dominates. Four of the seven apps use Highlight.js. None use alternatives like Prism.js or Shiki. Replit uses CodeMirror 6/Lezer instead.

Hidden WebView is common but not universal. ChatGPT, Claude, and Perplexity run hljs in an off-screen WebView, each loading it differently (file://, Base64 data:, WebViewAssetLoader). Le Chat takes a different approach — running highlight.js directly in the React Native JS thread without a separate WebView for tokenization.

Native rendering is the trend. Claude and Perplexity convert hljs HTML into native Compose spans. Le Chat renders via RN Text components with NativeWind styles. ChatGPT keeps everything in the WebView. GitHub uses native spans from server-provided HTML.

Perplexity is the most sophisticated native implementation. It produces both light and dark AnnotatedStrings from a single JS call, uses runtime CSS parsing instead of hardcoded color maps, and ships commercial monospace fonts.

Le Chat is the newest entrant. Mistral's app (Expo SDK 55, React Compiler enabled) bundles hljs grammars directly in Hermes bytecode and uses React Native Skia for potential custom rendering. It also ships Devicon for language icons — a nice UX touch.

Gemini is a shell. The 5 MB APK contains zero functionality — it exists only to launch the Google App where the real Gemini experience lives.

Replit chose code-reuse over native UX. As a full IDE app, Replit wraps their web-based CodeMirror 6 editor in a WebView with Lezer parsing (27+ token types), validating that native syntax highlighting on Android is hard enough that even well-funded teams avoid building it from scratch.

Analysis performed via static APK inspection — ADB extraction, apktool 3.0.2 decoding, smali bytecode analysis. No runtime instrumentation or decompilation tools were used. April–May 2026.
