Summary: Perplexity uses Highlight.js v11.11.1 for client-side syntax highlighting — the same library that Claude uses, but a newer version (11.11.1 vs 11.10.0) with significantly more bundled languages (192 vs 22). The highlighting runs inside a hidden WebView: Perplexity loads a local highlight.html page via WebViewAssetLoader, calls highlightCode(code, lang) via evaluateJavascript(), then parses the returned HTML spans and maps them to Compose AnnotatedString colors using a CSS parser that reads Tomorrow / Tomorrow Night theme files. Perplexity also bundles custom monospace fonts: Berkeley Mono and a proprietary Perplexity Mono.

Approach

Perplexity's architecture is strikingly similar to Claude's, with some key differences in execution:

  1. Hidden WebView — A WebView is created and loads highlight.html via Android's WebViewAssetLoader (URL: https://appassets.androidplatform.net/assets/highlight.html). This WebView is invisible to the user.
  2. JavaScript bridge — Code and language are passed into the WebView by calling evaluateJavascript() with the function highlightCode(code, lang). Highlight.js processes the code and returns the highlighted HTML.
  3. HTML parsing — The returned HTML (containing <span class="hljs-*"> tags) is parsed. The class gn/d ("jsHighlighter") reads the CSS theme files, builds a LinkedHashMap of class-to-color mappings, and walks the HTML DOM tree looking for <span> elements.
  4. Native rendering — The parsed colors are applied as Compose SpanStyle annotations, rendering in native Jetpack Compose UI with custom monospace fonts.

Code Fonts

Perplexity is the only analyzed app that bundles premium monospace fonts:

  • Berkeley Mono (Regular + Bold) — a well-known programming font by Neil Panchal
  • Perplexity Mono (Variable, beta) — a proprietary monospace font (pplx_mono_beta_v0_vf.ttf)

For comparison, ChatGPT and Claude use system monospace, and GitHub bundles Roboto Mono.

  • Maps integration — Mapbox SDK for location-based answers

Conclusions

Perplexity takes the most full-featured approach to syntax highlighting of all five apps. By bundling the complete Highlight.js library with 192 language grammars (vs. Claude's curated 22), it can highlight virtually any programming language a user might encounter. The Tomorrow/Tomorrow Night Base16 theme provides a clean, well-established color palette with strong contrast in both light and dark modes.

The WebView-based highlighting pipeline (hidden WebView → JavaScript execution → HTML parsing → native Compose rendering) is architecturally similar to Claude's approach, but Perplexity adds sophistication with a proper CSS parser that reads theme files at runtime (allowing potential future theme changes without code updates) and dedicated error handling via MarkdownException$HighlightJsFailed.

Beyond syntax highlighting, Perplexity differentiates itself by bundling premium typography (Berkeley Mono, a proprietary Perplexity Mono), LaTeX formula rendering (jlatexmath), and on-device ML models for voice activation and language detection — making it the most feature-rich APK of the five at 89 MB.

Analysis performed on APK extracted via ADB from an emulator. Decoded using apktool 3.0.2. All findings based on static analysis of smali bytecode, bundled assets, and resource files.
