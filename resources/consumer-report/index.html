Discovery Methodology & Reproduction Guide

Why doesn't GitHub Dependents show these repositories?
GitHub's native /network/dependents page only displays dependents when repositories push explicit Dependency Submission snapshots (SBOMs) to GitHub for Maven/Gradle artifacts. Standard Gradle builds resolving from Maven Central are not indexed automatically by GitHub's dependency graph.

To solve this, our automated discovery system uses a multi-vector code search pipeline:

  • Vector 1: Maven Coordinates - searches for dev.hossain:compose-highlight across all build files and catalogs.
  • Vector 2: Package Imports - searches for import dev.hossain.highlight across Kotlin/Java source files.
  • Vector 3: Version Catalogs - searches for compose-highlight in TOML version catalogs.

# Re-run live discovery against GitHub using gh CLI
