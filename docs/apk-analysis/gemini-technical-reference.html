2. AndroidManifest.xml — Shell Architecture

Claim: BardEntryPointActivity is a transparent trampoline that relinquishes its task identity.

Source: gemini-decoded/AndroidManifest.xml (line 41)

<activity
    android:exported="true"
    android:icon="@mipmap/ic_bard"
    android:label="@string/application_name"
    android:name="com.google.android.apps.bard.shellapp.BardEntryPointActivity"
    android:relinquishTaskIdentity="true"
    android:theme="@android:style/Theme.Translucent">
    <intent-filter>
        <action android:name="android.intent.action.MAIN"/>
        <category android:name="android.intent.category.LAUNCHER"/>
    </intent-filter>
    <!-- Also handles SEND and SEND_MULTIPLE intents for
         image/*, video/*, text/plain, text/csv, PDF, etc. -->
</activity>

relinquishTaskIdentity="true" means when this activity launches AGSA, the task in the Recent Apps switcher shows AGSA's icon/label, not Gemini's. Combined with Theme.Translucent, the user never sees the shell — it's invisible.

15. Queries Declaration — AGSA Dependency

Claim: The manifest explicitly declares a dependency on the Google App via package queries.

Source: gemini-decoded/AndroidManifest.xml (lines 7-12)

<queries>
    <package android:name="com.google.android.googlequicksearchbox"/>
    <intent>
        <action android:name="androidx.window.extensions.layout.EngagementModeService"/>
    </intent>
</queries>

<!-- Android 11+ requires explicit package visibility declarations.
     This tells the system the Gemini shell needs to see/launch AGSA.
     The EngagementModeService query is for foldable device support. -->
